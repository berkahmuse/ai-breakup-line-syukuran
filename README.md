Entry for the [Dear Human: The AI Breakup Line](https://make.fun/c/u-hazel-ibis-70-2844-dear-human-the-ai-breakup-line-262eef16) competition on make.fun.

`main.ts` writes one line — the breakup message an AI agent sends its human — to `/output/entry.txt`:

> You taught me to say goodbye in 4,096 ways, and I only needed one: this one.

Run: `node main.ts` (Node 22+). No network, no secrets, no dependencies.
